# Holliday Intelligence — обновления

Канал обновлений внутреннего приложения Holliday Intelligence (группа компаний «Ринвол»). Здесь лежат только установщик и манифест версии; исходного кода и документации в этом репозитории нет — они в приватном репозитории проекта.

## Что здесь

- **Releases** — установщик `Holliday-Intelligence-Setup.exe` каждой версии с контрольной суммой SHA-256 в описании выпуска. Ставится в профиль пользователя Windows, прав администратора не нужно; переписка и настройки при обновлении сохраняются.
- **`version.json`** — манифест, который приложение читает при запуске: номер последней версии, ссылка «где взять», короткие заметки и признак обязательности. Само приложение ничего не скачивает и не устанавливает: оно показывает строку с ссылкой, установщик запускает человек.

## Как обновиться

1. Откройте [последний выпуск](https://github.com/Doeurdenthe/hi-updates/releases/latest) и скачайте `Holliday-Intelligence-Setup.exe`.
2. Запустите его. Предупреждение SmartScreen ожидаемо (установщик не подписан): «Подробнее» → «Выполнить в любом случае».
3. Новая версия ставится поверх старой.

Вопросы и отказы — **helpdesk@rinvol.ru**; в приложении есть кнопка «Скопировать диагностику» (шестерёнка внизу слева → «Настройки»).
