# Holliday Intelligence — обновления

Канал обновлений внутреннего приложения Holliday Intelligence («Нити», группа компаний «Ринвол»). Здесь лежат только манифест версии и один выпуск-мост; исходного кода и документации в этом репозитории нет — они в приватном репозитории проекта.

## Что здесь

- **`version.json`** — манифест, который приложение читает при запуске: номер последней версии, ссылка «где взять», короткие заметки, признак обязательности, адрес установщика, его сумма SHA-256 и размер.
- **Releases** — единственный выпуск **0.32.0**, версия-мост: с нее приложение умеет обновляться само. Установщик `Holliday-Intelligence-Setup.exe` с контрольной суммой SHA-256 в описании выпуска. Ставится в профиль пользователя Windows, прав администратора не нужно; переписка и настройки при обновлении сохраняются.

Установщики версий новее 0.32.0 здесь не выкладываются: они лежат в закрытом хранилище выпусков, и приложение скачивает их само по ключу обновлений, который выдает ИТ-служба компании.

## Как обновиться

**С версии 0.31.4 и старше** (один раз, руками):

1. В приложении в строке «Доступна версия 0.32.0» нажмите «Скачать» — откроется страница этого выпуска; скачайте `Holliday-Intelligence-Setup.exe` и запустите. Предупреждение SmartScreen ожидаемо (установщик не подписан): «Подробнее» → «Выполнить в любом случае».
2. В окне установщика выберите «Установить поверх». Галочку «Удалить данные приложения», если она показана, не ставьте: у старых версий она стирает переписку.
3. После установки откройте «Настройки» → «Обновления», введите ключ обновлений, полученный от ИТ-службы, и нажмите «Сохранить».

**С версии 0.32.0 и новее** ничего скачивать не нужно: в строке «Доступна версия» нажмите «Обновить» — приложение скачает установщик, сверит сумму и поставит новую версию поверх, не задавая вопросов. Кнопка «Сохранить установщик…» рядом кладет тот же проверенный файл в папку без установки.

Вопросы и отказы — **helpdesk@rinvol.ru**; в приложении есть кнопка «Скопировать диагностику» (шестеренка внизу слева → «Настройки»).
